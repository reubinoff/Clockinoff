# Noto fonts (bundled)

These TTFs ship as static server-side assets so the PDF export report can
render Latin + Hebrew text (see `src/server/services/pdf.tsx`).

| File | Family | License |
|---|---|---|
| `NotoSans-Regular.ttf` | Noto Sans (Latin) | SIL Open Font License 1.1 |
| `NotoSans-Bold.ttf` | Noto Sans (Latin) | SIL Open Font License 1.1 |
| `NotoSansHebrew-Regular.ttf` | Noto Sans Hebrew | SIL Open Font License 1.1 |
| `NotoSansHebrew-Bold.ttf` | Noto Sans Hebrew | SIL Open Font License 1.1 |

Source: Google Noto fonts (<https://notofonts.github.io/>), redistributed
under the [SIL Open Font License 1.1](https://openfontlicense.org/).
